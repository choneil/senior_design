# RAMBo v1.2 Schematics

Schematic PDFs for the RAMBo (RepRap Arduino-compatible Mother Board) v1.2,
along with upscaled and upscaled/denoised individual sections. Upscaled versions were
made to be printable and legible after printing on 8.5x11 paper. 

## Contents

- `Rambo1-2g_Schematic.pdf` — 9 sheets, full schematic as given on reprap.org, as well as individual sections.
- `Rambo1-2g_Schematic_upscaled.pdf` — 9 sheets, same info, upscaled, a lot of artifacts, mostly included to show difference.
- `Rambo1-2g_Schematic_upscaled_denoised.pdf` — 9 sheets, same info, upscaled and denoised, most crisp version
- `rambov1.2/` — this folder contains all the sheets of the pdf as .png files. would be cool to turn into svg, but not very necessary.

## Source

RAMBo is an open-source 3D printer control board originally developed by
Ultimachine. The v1.2 schematic files here are from reprap.
